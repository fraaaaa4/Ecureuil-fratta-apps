# Ecureuil-fratta-apps
fratta Ecureuil source for all Windows apps, developed by fratta.

## What apps are included?
- **LocalSend32**: Win32/C LocalSend client for all versions of Windows from NT 3.51 onwards, including ARM32 and ARM64
- **Logix**: incomplete C# modern text editor for Prolog/LISP/etc
- **QuickView PDF**: WinForms lightweight PDF viewer
- **ReversiXP2003**: reimplementation of the classic Reversi game in WinForms
- **Clock 2002**: modern clock for Windows 2000 onwards with alarms, world clock, stopwatch, timer, and Pomodoro timer
- **Screen Snip**: screenshot and recording tool for Windows XP or superior with many features included, in a lightweight package
